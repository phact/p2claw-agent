# Generated UniFFI bindings

This directory holds the Swift wrapper around the Rust `p2claw-mobile`
crate. The file `p2claw_mobile.swift` is regenerated by
`mobile/ios/build-rust-xcframework.sh` (macOS only) and overwrites
anything in place. Do not edit by hand.

Reference copy of the same generated source lives at
`crates/p2claw-mobile/generated/swift/` for cross-platform review on
hosts without an iOS toolchain.
